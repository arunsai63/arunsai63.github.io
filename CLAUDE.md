# CLAUDE.md

## Project

OS-themed portfolio website. Three separate OS experiences: macOS (desktop), Android (mobile), iPadOS (tablet). Auto-detects device, switchable via `?os=` param or in-app OS switcher. Vanilla JS, Vite, Firebase. No frameworks.

Refer to `src/docs/` for architecture, per-OS guides, and how to add apps/widgets.
